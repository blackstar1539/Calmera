# Calmera

A private, browser-based wellness companion for teens and Gen Z. Calmera includes mood check-ins, a guided 4–7–8 breathing cycle, local-only journaling, affirmations, self-care ideas, and links to reputable support resources.

## Privacy

Mood and journal data are saved only in the visitor's browser with `localStorage`. There is no account, backend, analytics service, or remote data storage.

## Run locally

Open `index.html`, or serve the directory with any static web server.

## Important note

Calmera is a self-care tool, not medical advice or a replacement for professional or emergency support.
